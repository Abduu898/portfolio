Context & Objective

This hands-on project explores how a small embedded system can represent basic elevator behavior. The prototype combines a controller and a display so that control logic can be observed through a simple physical interface.

Architecture & Technologies

An Arduino Uno runs the control logic, while an I2C-connected LCD provides a compact display. The project brings together board setup, hardware connections, input and state handling, and display updates.

Challenges & Key Learnings

Embedded projects make software behavior depend on wiring, component configuration, and timing as well as code. A useful workflow is to test the display and controller separately first, then integrate the pieces and check each state transition.

This prototype is a starting point for learning how physical inputs, program state, and output devices work together.
