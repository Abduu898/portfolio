# 📚 Wikipedia-Inspired Computer Science Portfolio

A responsive, multi-page personal portfolio built with HTML5, CSS3, JavaScript, and Bootstrap 5. Designed around Wikipedia's Vector 2022 interface, this showcase documents my academic background, technical skills, software projects, and learning progression at **EMSI Tanger** and **Epitech Paris**.

---

## 🎯 Project Overview & Objectives

This portfolio serves as a central showcase of my technical journey, designed according to the requirements of the Epitech Discover IT curriculum:

- **Multi-Page Architecture:** Features a central hub (`index.html`) linking to dedicated article pages for every project and learning milestone.
- **Responsive & Accessible:** Fully adaptable to mobile, tablet, and desktop viewports, meeting basic web accessibility (WCAG) standards.
- **Zero Backend:** Built strictly using front-end technologies (HTML/CSS/JS) with no external database requirements.
- **Clear Reflection:** Documents project contexts, technologies, challenges encountered, and key learnings across the academic year.
