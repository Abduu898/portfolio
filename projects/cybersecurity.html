Context & Objectives

These projects explore practical defensive security from two complementary perspectives: protecting users from malicious links and protecting AI-agent tool interfaces from unauthorized actions. The objective is to build security-focused software that detects suspicious behavior, limits exposure, and produces useful evidence for investigation.

LinkShield

LinkShield is a Google Chrome extension built with Manifest V3 that inspects and analyzes URL structures locally using a lightweight heuristic detection engine. It is designed to help users identify suspicious links before visiting them without sending URLs to an external analysis service.

Key features

  • Real-time link verification.
  • Client-side URL parsing.
  • Zero-latency local execution without external API dependencies.
  • Visual risk indicators for potential phishing or typo-squatted domains.

Stack: JavaScript (ES6+), Chrome Extension API (Manifest V3), HTML5, and CSS3.

View the LinkShield repository

AgentHoneyPot

AgentHoneyPot is an experimental deception framework developed to safeguard AI agents and tool-calling interfaces against unauthorized data access and prompt-injection attacks. It adds a controlled deception layer between an agent and sensitive resources so suspicious activity can be contained and studied.

Key features

  • Detection of anomalous tool requests.
  • Interception of potential exploit payloads.
  • Routing of malicious actors to synthetic decoy datasets.
  • Detailed forensic artifact logging for security analyst inspection.

Stack: Python, threat deception architecture, and AI safety and security protocols.

View the AgentHoneyPot repository
