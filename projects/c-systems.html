Context & Objective

These coursework exercises build a practical foundation in C and Unix systems. The objective is to understand how programs represent and manipulate data, work with files, and interact with operating-system facilities.

Architecture & Technologies

The work covers C programming, data structures, file operations, pointers, and memory management. Unix/Linux topics include processes, pipes, command-line tools, and input/output redirection. Each exercise is developed and tested as a focused program or command-line task.

Challenges & Key Learnings

Low-level work requires careful attention to ownership, bounds, and return values. My debugging approach is to reduce a failure to a small reproducible case, inspect inputs and program state, check system-call results, and test edge cases after a change.

Working with processes and pipes also made it important to reason about where input and output flow, rather than treating each command as an isolated step.
