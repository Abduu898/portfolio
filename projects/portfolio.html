Context & Objective

This site presents my education, skills, experience, and projects in a familiar encyclopedia-inspired format. The goal is to make information easy to scan while keeping project details and learning reflections available as separate pages.

Architecture & Technologies

The site uses semantic HTML pages, a shared stylesheet, and a shared JavaScript file. Bootstrap provides responsive layout and common interface components; custom CSS supplies the Vector-like tabs, infoboxes, responsive rules, and dark theme.

Challenges & Key Learnings

One challenge has been making an information-dense layout work on narrow screens. I have had to check dropdown positioning, content order, and text wrapping at mobile sizes. The multi-page refactor also makes relative asset paths and consistent shared navigation important across directories.
