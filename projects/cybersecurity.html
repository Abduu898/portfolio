Context & Objective

These beginner exercises support my interest in defensive cybersecurity and how web systems can be assessed. The goal is to learn security fundamentals through guided, authorized environments and to build a careful, evidence-based testing process.

Architecture & Technologies

The current work consists of guided web reconnaissance and security fundamentals labs, including practice on TryHackMe. The focus is on understanding the structure of web applications, common risks, and the tools and methods used to investigate them in a controlled lab.

Challenges & Key Learnings

A key challenge is distinguishing useful evidence from assumptions. I work through a lab by documenting the objective, following its authorized scope, recording observations, and checking each conclusion against the available evidence.

These exercises are still introductory. I am building fundamentals before attempting more advanced testing or presenting lab results as professional security work.
